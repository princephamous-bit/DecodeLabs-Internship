# Sales Performance Analysis Dashboard
## Project Overview
An Excel-based sales analysis project designed to evaluate business performance and identify key sales trends and insights.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Visualization
- Dashboard & Slicers

## Key Insights
- Total Sales: $1,264,761.96
- Total Orders: 1,200
- Average Total Price: $1,053.97
- June recorded the highest monthly sales: $170,616.13
- Chairs generated the highest product revenue: $195,620.11
- Instagram generated the highest referral revenue: $275,285.45
- FREESHIP was the most-used coupon: 313 orders
- Cancelled orders were the highest order-status category: 250 orders

## Outcome
The project transformed raw sales data into an interactive dashboard that provides a clear overview of sales performance and supports data-driven business decisions.
